Numbered UX & HCI Annotations: Check URL & QR Code

  • 1

    Quishing (QR Code Phishing) Extension

    Tab clearly communicates dual functionality: users can inspect textual URLs or upload QR code screenshot images. The backend OpenCV pipeline automatically decodes the embedded payload without manual typing.

    Checklist 6: Multimodal OCR/QR Input
  • 2

    Forgiving Input & Protocol Normalization

    The input accepts partial URLs (e.g. google.com or 192.168.1.50) without enforcing strict protocol typing, normalizing them gracefully before ML scoring (Nielsen #5 Error Prevention).

    Checklist 2: Nielsen #5 Error Prevention
  • 3

    Technical Scam Vector Demonstrators

    Provides explicit demo chips categorized into raw numeric IP addresses, excessive multi-level subdomains, and obfuscated shortened URLs, educating users on common evasion techniques.

    Checklist 7: Educational Feedback & Explainability
  • 4

    Mobile Camera Capture Support

    On mobile viewports, the upload input specifies capture="environment", allowing users to photograph physical QR posters (e.g. at parking meters or cafes) with a single tap.

    Checklist 11: Mobile-First Touch Design
